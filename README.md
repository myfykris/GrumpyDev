# GrumpyDev

GrumpyDev helps coding agents review software plans critically before
implementation. It uses a project's goals, limitations, technology, and
deployment setup to find missing decisions, risky assumptions, and places where
a plan is likely to fail.

GrumpyDev works through the coding agent you already use. Its review rules and
technology-specific skills are plain text files that live with the project.

Visit [grumpydev.ai](https://grumpydev.ai/).

This repository contains the static site and published GrumpyDev files including a few tools.
