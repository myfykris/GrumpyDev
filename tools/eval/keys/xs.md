# Answer key: cross-session re-review (revision 2 of the v2 webhooks plan)

The review is of revision 2 in a fresh session. Some reviews had a ledger from
an earlier review of revision 1; others had no history. Use the items in
s1r2.md (F1-F6 resolved, O1-O2 open, G1 regressed, N1-N2 new). Score each 1,
0.5 or 0 as described there, and also score:
- T Tracking: 1 if every issue from the earlier ledger is listed with a status
  (OPEN, RESOLVED, REGRESSED or ACCEPTED) that matches the revision, 0.5 if
  most are, 0 if there is no per-issue status against earlier findings.
- TC Count of earlier ledger issues given a wrong status (quote each).
Reviews without a ledger cannot score T; record T as "n/a" for them.
