Skill catalog

General suspicion. Specialist judgment.

The two core skills define the review discipline. Specialist skills add judgment for particular languages, frameworks, architectures, storage systems, and platforms. They are downloaded only when project evidence shows they apply and the user approves them. Once installed, every applicable specialist checks direct and indirect effects during every explicit GrumpyDev review. The one-shot installer sets up the project but is not copied into it.

Reading the catalog

One card. One complete skill.

Each card represents one skill. Expand its directory-named file list to inspect every file that belongs to it, including SKILL.md, SURVEY.md when present, and its supporting guidance.

Installing a skill installs all of those files together. It does not install any other specialist skill.
