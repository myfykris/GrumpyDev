# Supabase survey contribution

## Applies when

Apply this contribution when the project uses or materially depends on Supabase
services.

## Inspect

- Read Supabase services, client versions, project configuration, migrations, schema, policies,
  functions, grants, and generated types.

## Ask when unresolved

- Which Supabase services, projects, regions, exposed schemas, identities, RLS
  policies, and connection paths apply?

- How are Auth, RPC, Edge Functions, Realtime, Storage, pooling, migrations,
  backups, limits, and recovery handled?

## Record

Map durable Supabase requirements and constraints to the matching doctrine
sections, runtime facts to `Runtime and deployment`, and material gaps to
`Unknowns`.
