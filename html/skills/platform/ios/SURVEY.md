# iOS and iPadOS survey contribution

## Applies when

Apply this contribution when software targets Apple mobile devices.

## Inspect

- Read minimum OS, Xcode, SDK, language, UI framework, dependency, build setting, and
  supported-device versions.

## Ask when unresolved

- Which Apple mobile OS versions, devices, UI framework, lifecycle,
  permissions, entitlements, and storage apply?

- How are background work, restoration, accessibility, signing, privacy
  manifests, upgrades, rollback, and review handled?

## Record

Map durable iOS and iPadOS requirements and constraints to the matching
doctrine sections, runtime facts to `Runtime and deployment`, and material gaps
to `Unknowns`.
