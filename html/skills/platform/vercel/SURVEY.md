# Vercel survey contribution

## Applies when

Apply this contribution when an application builds or runs on Vercel.

## Inspect

- Read framework, Vercel project, build, output, function runtime, region, route, cache,
  domain, and environment configuration.

## Ask when unresolved

- Which Vercel projects, framework, runtimes, regions, Fluid settings, limits,
  build output, and data locations apply?

- How are concurrency, global reuse, connections, caches, environments,
  previews, domains, rollout, and rollback handled?

## Record

Map durable Vercel requirements and constraints to the matching doctrine
sections, runtime facts to `Runtime and deployment`, and material gaps to
`Unknowns`.
