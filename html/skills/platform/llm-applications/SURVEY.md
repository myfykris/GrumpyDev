# LLM applications survey contribution

## Applies when

Apply this contribution when application behavior depends on a generative model.

## Inspect

- Read model providers and versions, system prompts, templates, context assembly, tools, output
  schemas, and sampling settings.

## Ask when unresolved

- Which models, versions, effort settings, prompts, schemas, retrieval, data
  classes, and provider regions apply?

- How are injection, hidden context, data and model poisoning, output
  validation, agency, retrieval isolation, evaluations, privacy, citations,
  consumption, observability, fallbacks, and rollback handled?

## Record

Map durable LLM applications requirements and constraints to the matching
doctrine sections, runtime facts to `Runtime and deployment`, and material gaps
to `Unknowns`.
