# Qt survey contribution

## Applies when

Apply this contribution when the project uses or materially depends on Qt.

## Inspect

- Read Qt and compiler versions, object trees, signal and slot connections,
  thread use, models, QML boundaries, resource packaging, target platforms, and
  tests.

## Ask when unresolved

- Which Qt, C++ compiler, platform, rendering backend, and ownership model
  apply?

- How do parent ownership, signals, threads, event loops, shutdown,
  accessibility, and native resources interact?

- Which runtime or deployment differences materially change future reviews: Qt
  version, language binding, OS and window-system targets, platform plugins,
  native libraries, architecture, packaging, signing, display environment, and
  update channel?

## Record

Map durable Qt version and behavior requirements to `Requirements` or
`Constraints`, lifecycle and deployment facts to `Runtime and deployment`, and
material gaps to `Unknowns`.
