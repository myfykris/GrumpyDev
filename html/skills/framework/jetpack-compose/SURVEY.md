# Jetpack Compose survey contribution

## Applies when

Apply this contribution when the project uses or materially depends on Jetpack Compose.

## Inspect

- Read Compose BOM and compiler compatibility, Kotlin and Android plugin versions, navigation,
  state, and dependency injection choices.

## Ask when unresolved

- Which Compose, Kotlin, Android plugin, SDK, navigation, state, and dependency
  injection versions apply?

- How do state, effects, process recreation, accessibility, adaptive layouts,
  permissions, and performance behave?

## Record

Map durable Jetpack Compose version and behavior requirements to `Requirements`
or `Constraints`, lifecycle and deployment facts to `Runtime and deployment`,
and material gaps to `Unknowns`.
