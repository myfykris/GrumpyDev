# Expo survey contribution

## Applies when

Apply this contribution when the project uses or materially depends on Expo.

## Inspect

- Read Expo SDK, React Native, React, router, module, config-plugin, and native project
  versions.

## Ask when unresolved

- Which Expo SDK, React Native version, platforms, workflow, native modules,
  EAS profiles, and minimum OS versions apply?

- What runtime-version, channel, rollout, rollback, signing, permission, and
  generated-native-code policy applies?

## Record

Map durable Expo version and behavior requirements to `Requirements` or
`Constraints`, lifecycle and deployment facts to `Runtime and deployment`, and
material gaps to `Unknowns`.
