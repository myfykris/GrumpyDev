# Next.js survey contribution

## Applies when

Apply this contribution when the project uses or materially depends on Next.js.

## Inspect

- Read Next.js and React versions, app or pages router, route configuration,
  server and client components, caching directives, middleware, runtime targets,
  and tests.

## Ask when unresolved

- Which Next.js, React, router, rendering mode, cache mode, and deployment
  runtime apply?

- Where do authentication, server actions, route handlers, revalidation,
  serialization, and client state cross boundaries?

- Which runtime or deployment differences are material for future reviews:
  Node, edge, serverless, static, and client runtimes; build-time versus
  request-time data; cache and revalidation ownership; regions; assets; and
  deployment platform?

## Record

Map durable Next.js version and behavior requirements to `Requirements` or
`Constraints`, lifecycle and deployment facts to `Runtime and deployment`, and
material gaps to `Unknowns`.
