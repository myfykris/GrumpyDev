# Tailwind CSS survey contribution

## Applies when

Apply this contribution when the project uses or materially depends on Tailwind CSS.

## Inspect

- Read the Tailwind version, CSS entrypoints, source detection, theme tokens, plugins,
  framework integration, and build command.

## Ask when unresolved

- Which Tailwind version, framework integration, source roots, theme tokens,
  plugins, and browser targets apply?

- How are dynamic variants, shared packages, production scanning, accessibility
  states, CSS ordering, and size verified?

## Record

Map durable Tailwind CSS version and behavior requirements to `Requirements` or
`Constraints`, lifecycle and deployment facts to `Runtime and deployment`, and
material gaps to `Unknowns`.
