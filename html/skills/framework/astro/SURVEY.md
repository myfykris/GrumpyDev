# Astro survey contribution

## Applies when

Apply this contribution when the project uses or materially depends on Astro.

## Inspect

- Read the Astro, adapter, integration, and UI framework versions plus output mode and route
  settings.

## Ask when unresolved

- Which Astro version, output mode, adapter, host, routes, and client
  integrations apply?

- Which routes are prerendered or rendered on demand? Within those pages, which
  components need client hydration or deferred server rendering?

## Record

Map durable Astro version and behavior requirements to `Requirements` or
`Constraints`, lifecycle and deployment facts to `Runtime and deployment`, and
material gaps to `Unknowns`.
