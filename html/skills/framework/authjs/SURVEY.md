# Auth.js survey contribution

## Applies when

Apply this contribution when the project uses or materially depends on Auth.js.

## Inspect

- Read the Auth.js package and framework adapter versions, provider setup, callbacks, events,
  and route wiring.

## Ask when unresolved

- Which Auth.js version, framework adapter, providers, session strategy,
  database adapter, and deployment origins apply?

- How are accounts linked, provider credentials refreshed, sessions revoked,
  cookies scoped, and resources authorized?

## Record

Map durable Auth.js version and behavior requirements to `Requirements` or
`Constraints`, lifecycle and deployment facts to `Runtime and deployment`, and
material gaps to `Unknowns`.
