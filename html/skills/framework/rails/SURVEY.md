# Ruby on Rails survey contribution

## Applies when

Apply this contribution when the project uses or materially depends on Ruby on Rails.

## Inspect

- Read Rails and Ruby versions, routes, middleware, models and migrations,
  callbacks, jobs, caches, credentials, server and worker configuration, and
  tests.

## Ask when unresolved

- Which Ruby, Rails, database, job adapter, cache, and application-server
  versions apply?

- How do callbacks, validations, transactions, authorization, autoloading,
  jobs, and migrations interact?

- Which runtime or deployment differences materially change future reviews:
  Ruby and Rails versions, application server, process and thread counts,
  proxy, cache, sessions, Active Job adapter, file storage, migrations, assets,
  restart, and rollback?

## Record

Map durable Ruby on Rails version and behavior requirements to `Requirements`
or `Constraints`, lifecycle and deployment facts to `Runtime and deployment`,
and material gaps to `Unknowns`.
