# Vue survey contribution

## Applies when

Apply this contribution when the project uses or materially depends on Vue.

## Inspect

- Read Vue and build-tool versions, component API style, router, store and data
  libraries, rendering mode, plugins, configuration, and tests.

## Ask when unresolved

- Which Vue, JavaScript or TypeScript, build tool, router, state library,
  rendering mode, and browser versions apply?

- Who owns reactive state, effects, async work, hydration, errors,
  authorization, and accessibility behavior?

- Which runtime or deployment differences materially change future reviews:
  Client-only, SSR, static, or hybrid mode; Node server if any; browser
  targets; build output; base path; proxy; cache; hydration; and hosting?

## Record

Map durable Vue version and behavior requirements to `Requirements` or
`Constraints`, lifecycle and deployment facts to `Runtime and deployment`, and
material gaps to `Unknowns`.
