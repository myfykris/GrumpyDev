# React survey contribution

## Applies when

Apply this contribution when the project uses or materially depends on React.

## Inspect

- Establish React and framework versions, rendering mode, routing, data and
  form libraries, build output, tests, and supported browsers.

## Ask when unresolved

- Which React version, JavaScript or TypeScript version, framework, rendering
  mode, and supported browsers apply?

- Who owns server data, URL state, form state, effects, hydration, errors, and
  accessibility behavior?

- Which runtime or deployment differences materially change future reviews:
  Client-only, SSR, streaming, server-component, native, or embedded target;
  browser and server runtimes; build output; cache; content security policy;
  and hosting base path?

## Record

Map durable React version and behavior requirements to `Requirements` or
`Constraints`, lifecycle and deployment facts to `Runtime and deployment`, and
material gaps to `Unknowns`.
