# React Native survey contribution

## Applies when

Apply this contribution when the project uses or materially depends on React Native.

## Inspect

- Read React Native, React, platform, engine, native module, navigation, and state-library
  versions.

## Ask when unresolved

- Which React Native, React, engine, architecture, platforms, OS versions, and
  native modules apply?

- How are threads, lifecycle, navigation, permissions, offline state,
  accessibility, signing, and release behavior handled?

## Record

Map durable React Native version and behavior requirements to `Requirements` or
`Constraints`, lifecycle and deployment facts to `Runtime and deployment`, and
material gaps to `Unknowns`.
