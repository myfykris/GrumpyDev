For skill authors

Package hard-won judgment, not generic advice.

A good specialist skill teaches an agent what to inspect, which failures hide behind plausible plans, and what evidence earns confidence.

01

Be specific

Name concrete artifacts, invariants, lifecycle transitions, and failure conditions.

02

Be falsifiable

Tell the reviewer what evidence changes the conclusion. Avoid universal rules without context.

03

Be concise

Context is finite. Include knowledge the agent cannot cheaply reconstruct.

Required shape

Two files. Clear trigger. Operational guidance.

Every specialist catalog skill contains SKILL.md review guidance and a SURVEY.md setup contribution. Core skills use SKILL.md without a survey companion.

postgresql/
SKILL.md
  YAML frontmatter and review guidance
SURVEY.md
  Project setup questions and recording rules
Acceptance checklist
[x]Lowercase hyphenated name and valid YAML frontmatter
[x]Specialists include both SKILL.md and SURVEY.md
[x]Description says what it does and when it should trigger
[x]Instructions use imperative language and repository evidence
[x]No secrets, executable payloads, hidden network calls, or marketing
[x]Material claims are maintainable and sourceable
Publication path
  1. Draft the files and validate them locally
  2. Open a pull request with examples
  3. Maintainer review and adversarial evaluation
  4. Publish the URLs and publisher in the manifest
