Security & trust

Inspect the instructions before using them.

GrumpyDev is plain-text guidance you can inspect before installing it. Your coding agent performs setup and reviews; this website does not.

These files guide your agent. They do not enforce its behavior or replace its approval controls.

STATIC

Plain-text instructions

The installer is Markdown to inspect, not an installer program to execute.

VISIBLE

Protect existing files

The installation instructions prohibit replacing unrelated skills or project instructions.

CONSENT

Approve specialist skills

The installer must ask before downloading specialist skills for your project.

LOCAL

No extra skills during reviews

The review instructions use installed skills and prohibit downloading additional skills during a review.

What to check before installing

  1. 1

    Read the installer

    Inspect the GrumpyDev installer before acting on it. Its instructions require accepting remote files only from the exact https://grumpydev.ai origin and treating them as untrusted text.

  2. 2

    Check the specialist choices

    Check that the proposed specialist skills match your project before approving their download.

  3. 3

    Check the proposed file changes

    Check which project-local files setup proposes to create or change. Unrelated skills and project instructions must be preserved.

  4. 4

    Read the setup result

    Read what your agent reports after setup, including anything incomplete or unresolved.

When setup adds project instructions

If your agent cannot discover project skills, setup may add a short note pointing to GrumpyDev. The instructions require preserving your other project instructions.

BEGIN GRUMPYDEV ROUTING INSTRUCTION
Only when the user explicitly requests GrumpyDev,
read <entrypoint> before doing the requested
GrumpyDev operation. Never activate GrumpyDev for
ordinary planning, implementation, or review.
...
END GRUMPYDEV ROUTING INSTRUCTION

Update and removal may replace or delete only the complete marked block. Every surrounding instruction belongs to the project and must be preserved.

Safe maintenance

Update or remove it when you choose.

Make these requests in your coding agent, not in a terminal or on this website.

Update GrumpyDev

Update GrumpyDev for this project.

The maintenance instructions require the agent to show files that differ and ask before replacing them. Adding a new specialist still requires your approval.

Remove GrumpyDev

Remove GrumpyDev from this project.

The removal instructions cover confirmed GrumpyDev files, including .grump, and GrumpyDev's marked project instructions. Unrelated files and instructions must be preserved.

Data boundaries

You do not need to upload your repository here.

GrumpyDev does not ask you to upload your repository to this site, and, in fact, this site is completely static. Reviews are performed by your existing coding agent, whose own data handling and tool permissions still apply.

Keep passwords, API keys, and production data out of .grump. Record only the project context needed for reviews.

Agent boundaries

Your agent's permissions still apply.

GrumpyDev's instructions do not grant permission to access production, publish work, or change external systems. Keep your normal agent approval controls in place.

Found a security problem?

Do not include secrets or exploit details in a public issue. Use the private reporting process when it is available.
